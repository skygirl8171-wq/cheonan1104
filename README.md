# 천안시 생성형 AI 웹 프레젠테이션

첨부된 `천안시AI교육.pptx`의 8개 슬라이드를 기반으로 만든 반응형 정적 웹 프레젠테이션입니다.

## 실행

`index.html`을 브라우저에서 열면 동작합니다. 별도의 서버, 데이터베이스, 빌드 도구가 필요하지 않습니다.

## GitHub Pages 게시

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 `index.html`, `styles.css`, `script.js`, `assets/`을 **저장소 최상위**에 업로드합니다.
3. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. **Branch: main / Folder: /(root)** 를 지정하고 저장합니다.
5. 생성된 `https://<계정>.github.io/<저장소>/` 주소로 접속합니다.

이미지 경로는 `./assets/...` 상대 경로를 사용하므로 프로젝트 저장소 형태의 GitHub Pages에서도 작동합니다. Google Fonts를 사용하지만 외부 폰트 연결이 끊겨도 시스템 한글 글꼴로 표시됩니다. 모든 내용과 사진·아이콘은 저장소 안에 포함되어 있습니다.

## 조작 방법

- 상단 목차: 각 슬라이드로 이동
- 화면 우하단 이전·다음 버튼
- 키보드: ←, →, PageUp, PageDown, Space, Home, End
- 모바일: 세로 스크롤 / 상단 목차 메뉴
- 애니메이션 최소화 OS 설정을 지원합니다.

## 원본 대응

슬라이드 1~8의 제목, 본문, 도구명, 강조 문구, 교육 현장 이미지, 아이콘을 유지했습니다. 표지 도시 실루엣은 HTML/CSS 요소로 재구성했습니다. 원본 PPTX는 '천안시 청년정책'이 아닌 '천안시 시민 대상 AI 교육' 내용입니다.
